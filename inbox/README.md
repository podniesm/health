# Inbox

Wrzucaj tutaj surowe pliki, a potem wpisz `/import` w Claude Code.

Co można wrzucić:
- PDF-y i zdjęcia wyników badań (dowolne laboratorium)
- eksporty CSV z Garmin Connect, Strava, Polar Flow
- eksport XML z Apple Health
- eksporty z wagi (Withings, Xiaomi/Zepp, Garmin Index)
- wypisy, zalecenia lekarskie, opisy badań obrazowych (PDF/zdjęcie)

Po przetworzeniu pliki są przenoszone do `archive/`. Ten README zostaje.
